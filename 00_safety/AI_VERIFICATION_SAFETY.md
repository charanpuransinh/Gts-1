# GTS AI VERIFICATION SAFETY

1. AI MUST NOT claim PASS without real test evidence.
2. Every test command, exit code, stdout and stderr MUST be recorded.
3. File inventory and SHA256 hashes MUST be recorded.
4. Missing, skipped or failed tests MUST be reported exactly.
5. AI MUST NOT modify test results, logs or verification evidence.
6. PASS requires actual commands to return success.
7. Any uncertainty = NOT VERIFIED.
8. Owner has final authority.
